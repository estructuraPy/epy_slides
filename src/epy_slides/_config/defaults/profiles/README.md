# _config/defaults/profiles — named user default-sets

**Author:** Ing. Angel Navarro-Mora M.Sc.

Named profiles saved via DefaultsManager (epy_analysis.epy_suite_connect._data._defaults):
save_profile / load_profile / list_profiles / delete_profile. Each profile is
itself a defaults set (<name>.epyson), resolved AFTER the base defaults/ files.
The user can also save a profile by editing a file here directly.
